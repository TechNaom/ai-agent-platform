# ADR-0001: Record architecture decisions

- Status: Accepted · 2026-09-30

## Context
Several AI assistants and humans work on this repo across sessions. Decisions that
live only in chat get re-litigated or silently reversed.

## Decision
Record every significant architectural decision as an ADR in `docs/adr/`.

## Consequences
PRs that change architecture must add or supersede an ADR. `AI_HANDOFF.md` points here.
